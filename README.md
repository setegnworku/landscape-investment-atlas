# Landscape Investment Atlas

A decision-support concept for directing investment toward multifunctional landscapes — from landscape assets to investment returns.

## Live site

After GitHub Pages is enabled, the site is published from the `docs/` folder:

`https://<your-username>.github.io/landscape-investment-atlas/`

## Local preview

```bash
cd docs
python -m http.server 8765
```

Open http://localhost:8765

## Contents

- `docs/` — Interactive project website (GitHub Pages)
- `website/` — Development copy (keep in sync with `docs/` when updating)
- Word documents — Framework drafts and programmer dashboard specification

## Framework summary

The Landscape Investment Atlas helps identify where investment in landscapes can generate the greatest benefits for people, nature, and economies — using L-ROI, multifunctionality (MDI), and investor-fit analysis across Living Landscapes.
